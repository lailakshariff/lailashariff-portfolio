# Deploy the SayPlay update

Repo: lailakshariff/lailashariff-portfolio · branch main. Vercel deploys from the `dist/` folder.

## Upload on GitHub (no terminal)
1. Unzip this download.
2. Open github.com/lailakshariff/lailashariff-portfolio and click **Add file → Upload files**.
3. Drag the **dist** folder from inside the unzipped folder onto the page. GitHub keeps the folder paths, so the files land in `dist/` and `dist/assets/` and replace the old ones.
4. Commit message: `SayPlay: new prototype screens + live prototype page`. Choose **Commit directly to main** and click **Commit changes**.
5. Vercel redeploys automatically in about a minute. Check it on the Deployments tab.

## What's included (58 files)
- dist/sayplay.html: the case study with new screens and tablet/phone spacing fixes
- dist/sayplay-proto.html: the working prototype (new page)
- dist/assets/sp3-*.webp: 9 new case study screens
- dist/assets/sp2t-*.png and sp-ic-lion2.png: 46 symbols the prototype needs

## After it's live
- Open /sayplay.html and check the hero and carousel show the new screens.
- Click "Try the working prototype". Open the Food, Sports and Actions boards to check the symbols load.
